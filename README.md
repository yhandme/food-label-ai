# 食安标签通

> AI 食品标签解读与添加剂科普网站
> 《人工智能基础与应用》课程大作业

## 项目简介

「食安标签通」是一个面向普通消费者的食品安全科普网站。用户选择食品类别、粘贴包装上的配料表、按营养成分表填几个数字，网站就会逐项识别其中的食品添加剂，给出添加剂维度的 A/B/C 评估、营养维度的红绿灯与叶子评分、NRV% 每日参考值，并检查常见致敏物质，最后生成一张可截图保存的贴纸摘要卡。

**在线访问：** https://yhandme.github.io/food-label-ai/

**项目仓库：** https://github.com/yhandme/food-label-ai

**演示视频：** 84 秒，1920×1080，从选择类别到生成摘要完整走一遍（随作业提交，文件 `演示视频_食安标签通.mp4`，未入库）

## 核心功能

| 功能 | 说明 |
|---|---|
| 标签解读工作台 | 四步录入：食品类别 → 配料表 → 营养成分 → 添加剂，一次生成完整解读 |
| 配料表小助手 | 粘贴即实时识别，逐项标出已识别的添加剂与总数；支持整理格式、一键粘贴 |
| 添加剂识别与补充 | 自动识别配料中的添加剂，也可从知识库手动挑选或输入自定义名称 |
| 营养红绿灯 | 能量、脂肪、糖、钠四项按每 100 g（饮料另用更严格阈值）分低/中/高三档 |
| 营养小叶子评分 | 0.5–5 片叶子的营养评分，含糖密度修正与蛋白质、膳食纤维加分 |
| NRV% 每日参考值 | 7 项营养素的 NRV% 与进度条，参考 GB 28050 |
| 添加剂科普卡片 | 每种添加剂附类别、用途、注意事项、ADI 限量与致敏提示，可点开详情 |
| 过敏原提示 | 内置八类致敏物质 + 亚硫酸盐词典，支持「我的过敏原」设置，命中项标红 |
| 贴纸摘要卡 | 奶油色贴纸样式的结果摘要，可点击复制摘要文字，或一键导出 PNG 图片 |
| 打印导出 | 在结果页按 Ctrl+P 直接输出干净的 A4 / PDF：导航、按钮、侧栏自动隐藏，卡片不被切断 |
| 历史记录 | 最近 8 次解读保存在本地，可一键重新载入或删除 |
| 结果复制 | 摘要版与完整版两档文本，一键复制到剪贴板 |
| 每日一贴 | 30 条读标签小知识，按日期轮换（约一个月不重样），可手动换一条 |
| 添加剂科普库 | 85 种常见添加剂，按 15 类功能筛选、关键词搜索（支持名称、INS 编码、功能类别、俗称）、详情查看 |
| 食品安全问答 | 27 条知识条目 + 85 种添加剂名片检索，覆盖添加剂、标签法规、营养与选购话题 |
| 关于本站 | 设计取向、技术实现、数据依据三段说明，条目数由数据自动生成 |

## 设计风格

整体采用**现代食品科学实验室**的视觉基调：专业、理性、可信赖，同时用暖色层让它不显得冷。

- **色彩**：主色柔和绿 `#3A7D44`，页面底色改为暖白纸感 `#FBFAF6`；辅色浅薄荷 `#E8F3EC`、奶油 `#FBF3E3`、浅灰蓝 `#F2F6F8`。语义色去饱和后与主色同色温（良好 `#3A7D44` / 留意 `#C08A2E` / 关注 `#B4483F`）
- **卡片**：白底、1px 浅边框、16px 圆角，阴影只保留极淡一层，靠边框而非阴影分隔
- **排版**：标题用清晰无衬线字体；数据标签用小号大写 + 字距（如 `SAMPLE NOTE`、`INS 202`）；INS 编码与限量值使用等宽字体与 `tabular-nums`；贴纸卡标题用衬线体，像一张手写标签
- **质感**：极淡点阵网格 + 刻度虚线，取样单的观感；奶油色区块（每日一贴、贴纸卡）提供温度
- **图标**：统一 1.5px 描边线性 SVG，另有少量可爱元素（实验烧瓶小伙伴、手绘叶簇）
- **评估呈现**：添加剂用 A/B/C 等级 + 分项计数，营养用红绿灯 + 叶子评分，两个维度分开呈现，避免让规则化估算显得像精确测量

## 技术路线

- **前端**：原生 HTML5 + CSS3 + JavaScript（ES6），无框架、无构建步骤
- **部署**：纯静态文件，可直接托管于 GitHub Pages
- **数据**：本地 JS 知识库（85 种添加剂 / 15 个分类 / 9 类过敏原 / 7 项营养素 / 6 个示例标签 / 30 条每日一贴 / 27 条问答）
- **本地存储**：过敏原设置与历史记录保存在浏览器 `localStorage`，不上传服务器
- **AI 实现说明**：标签解读采用「规则匹配 + 知识库」的本地智能分析；营养分级采用阈值判定 + 加权评分；问答采用关键词匹配。全部计算在浏览器本地完成，不上传用户输入，不依赖外部 API。这一设计保证了离线可用性与数据隐私，也如实体现课程对「AI 能力与局限」的认识要求。

## 计算口径说明

- 营养数值按包装营养成分表的**每 100 g / 每 100 mL** 填写
- 红绿灯阈值：脂肪 3 / 17.5 g、糖 5 / 22.5 g、钠 120 / 600 mg（每 100 g，参考英国 FSA 前端标识）；饮料另用更严格的一套（糖 2.5 / 11.5 g、脂肪 1.5 / 8.75 g、钠 120 / 300 mg，每 100 mL）；能量无国际统一标准，本站取 400 / 1200 kJ 作参考区间
- NRV 参考 GB 28050：能量 8400 kJ、蛋白质 60 g、脂肪 60 g、碳水化合物 300 g、钠 2000 mg、膳食纤维 25 g；糖按 WHO 建议上限 50 g 计
- 叶子评分从 5 片起算，每项「偏高」扣 1.3、「适中」扣 0.6，糖按密度额外扣分，蛋白质与膳食纤维充足则加分，最终落在 0.5–5 之间
- 添加剂参考分从 100 起算：每种「需留意」扣 13、「关注」扣 26、「未收录」扣 8；安全级别的添加剂不扣分（在规定用量下没有扣分依据，扣了会让 A 级配上 70 分，自相矛盾）
- 过敏原识别基于关键词匹配，覆盖八类致敏物质与亚硫酸盐，不能替代包装上的致敏物质提示
